## Beginners Guide

* For windows user
    Click `run.bat`
    chose **FOLDER** pathway.
    chose RGB changer, enter your **Bright & Contrast** `max` and `min` value and also choose the color.
* For IOS user
 :::warning 
click `.jar` file insted of clicking `run.bat` 
 :::
